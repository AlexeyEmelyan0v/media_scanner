## Описание

`media_scanner` — консольное приложение на C++ для Linux, которое периодически обходит указанную директорию, находит в ней мультимедийные файлы и сохраняет результат в JSON-файл `.media_files`.

Приложение определяет тип файла по его расширению и распределяет найденные файлы по трём категориям:

* `audio` — аудиофайлы
* `video` — видеофайлы
* `images` — изображения

По умолчанию приложение сканирует домашнюю директорию пользователя `$HOME` с интервалом 10 секунд. При запуске можно указать другую директорию и другой интервал сканирования. Результирующий файл `.media_files` создаётся внутри сканируемой директории и перезаписывается при каждом новом обходе, чтобы содержать актуальный список найденных файлов.


## Сборка
```
cmake -S . -B build
cmake --build build
```

## Запуск
Запуск без аргументов:
```
./build/media_scanner
```
В этом случае приложение сканирует домашнюю директорию `$HOME` с интервалом 10 секунд.

Запуск с указанием директории и интервала:
```
./build/media_scanner [директория] [интервал_в_секундах]
```
Результат записывается в файл `.media_files` внутри сканируемой директории.
